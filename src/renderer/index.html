    A task is a pane that keeps its own conversation, its own attached files and its own streaming answers. Point it at any endpoint you have configured.

    1. Add an endpoint in Settings — hosted API or local server.
    2. Pick a workspace folder and tick the files that matter.
    3. Ask, and watch the answer stream into the task pane.
